# 架构决策记录（ADR）

当前没有经单独确认的历史 ADR。本目录规定后续记录方式；[架构文档](../architecture.md) 描述现状，不代表所有实现都是已认可的长期选择。

涉及身份协议、消息投递语义、状态所有权、数据库/队列替换或跨服务部署拓扑时，增加 `NNNN-short-title.md`。普通 bug 修复或文案修改无需 ADR。

建议结构：

```text
标题：NNNN 具体决策
状态：proposed / accepted / superseded
背景：触发问题、限制、现有源码入口
选择：方案、影响模块、协议/数据变化
备选：考虑过的方案及取舍
结果：兼容、迁移、运行与维护成本
验证：验收条件、测试/指标、回滚方式
```

未批准的设计标注 proposed；不要把 agent 推测或待办自动标为 accepted。
